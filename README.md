# Karpathy Zero to Hero — Learning Neural Networks from Scratch

My personal implementations, copied notebooks, experiments and notes while following Andrej Karpathy's *Neural Networks: Zero to Hero* course.

The goal of this repository is to develop a deeper understanding of neural networks, automatic differentiation, backpropagation, and deep learning by implementing the underlying mechanics from scratch; eventually even adding my own work and trying to train some small personal neural networks on specific datasets.

## Progress

**Micrograd — Autograd and Backpropagation**

- Implemented a scalar-valued automatic differentiation engine.
- Built computational graphs and implemented backpropagation.
- Developed a simple multilayer perceptron (MLP).
- Implemented gradient descent to train the network.
- Explored how PyTorch handles gradients.
